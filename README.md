# LYNKO Keyboard

Offline Android keyboard (English + Sinhala) with themes, one-handed mode, clipboard tools and a settings panel.

## Files (folders නැහැ)
settings.gradle · build.gradle · gradle.properties · AndroidManifest.xml · method.xml · LynkoIME.java · MainActivity.java · README.md

## Build
1. Android Studio → Open → මේ folder එක select කරන්න (Gradle wrapper එක auto generate වෙනවා).
2. Run → phone එකට install.
3. App එක open කරලා Setup screen එකේ keyboard enable + select කරන්න.

## Done
Themes (Auto/Dark/Light/Purple/Neon), key transparency/roundness/height/text size, one-handed mode,
vibration/sound, number row, Sinhala layout, cut/copy/paste/select-all/cursor, privacy mode,
saved themes, backup/restore, live preview, 6 screens.

## Roadmap (තාම නැහැ)
Voice typing, translator, AI assistant, swipe typing, floating/split keyboard.
